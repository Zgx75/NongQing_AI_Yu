# 農情「AI」語－使用說明書

版本：1.0
線上網站：<https://nong-qing-ai-yu.vercel.app>

農情「AI」語是一套協助臺灣農民整理農務紀錄、產銷履歷申報草稿與品牌文案的系統。主要操作流程是：

```text
輸入農務內容 → AI 整理欄位 → 人工修正與補充 → 預覽 → 儲存草稿 → 人工確認
```

> AI 只負責協助整理，不代表內容一定正確。正式使用前，務必由農民或授權人員逐項確認。

## 一、開始使用

### 1. 進入網站

開啟：<https://nong-qing-ai-yu.vercel.app>

首頁提供三個主要入口：

- **登入**：已有帳號時使用。
- **註冊**：第一次使用時建立帳號。
- **示範模式**：不需登入即可體驗操作，不會將示範資料存入正式農場。

建議先使用手機或平板操作。系統按鈕與欄位已針對觸控操作設計。

### 2. 註冊帳號

按下「免費開始使用」或「立即註冊」，依序填寫：

1. 姓名
2. Email
3. 密碼，至少 8 個字元
4. 使用者角色
5. 勾選資料使用聲明

可選角色：

| 角色 | 適用對象 | 主要權限 |
| --- | --- | --- |
| 農民 `FARMER` | 農場主人或實際耕作者 | 建立農場、田區、農務紀錄、文案與匯出 |
| 農會／合作社 `COOPERATIVE` | 協助農戶整理資料的人員 | 依農場授權查看或協助處理資料 |
| 管理員 `ADMIN` | 系統管理者 | 管理使用者、提示詞、農業詞彙與稽核紀錄 |

一般註冊頁不提供管理員角色。管理員權限必須由現有系統管理者授予。

第一位管理員應先完成一般註冊，再由部署管理者在安全的終端機設定 `ADMIN_EMAIL` 並執行 `pnpm admin:promote`。升級完成後，系統會撤銷該帳號既有 Session，使用者必須重新登入。

### 3. 登入與登出

- 使用註冊 Email 與密碼登入。
- 桌面版可在左側欄底部找到「登出」。
- 手機版可透過頁面上方的使用者資訊確認目前登入身分。
- 請勿在公共電腦上保持登入；使用完畢後應主動登出。

## 二、介面導覽

登入後可使用以下主要功能：

| 選單 | 用途 |
| --- | --- |
| 總覽 | 查看本月紀錄、待確認資料、最近紀錄與快捷入口 |
| 農場與田區 | 建立農場、田區、面積與主要作物資料 |
| 新增紀錄 | 以文字、語音或照片建立農務紀錄 |
| 歷史紀錄 | 搜尋、查看、列印與匯出既有紀錄 |
| 品牌文案 | 建立品牌資料並產生多種文案草稿 |
| 資料佐證 | 查看外部資料來源、查詢時間與取得狀態 |
| 管理後台 | 僅管理員可進入 |

手機使用底部導覽列，桌面則使用左側導覽列。

## 三、第一次建立農場

正式保存農務紀錄前，必須先建立農場。

### 1. 建立農場

1. 登入後進入「農場與田區」。
2. 按下「建立農場」。
3. 填寫農場名稱、縣市、鄉鎮市區、地點描述與主要聯絡人。
4. 視需要填寫農法與農場介紹。
5. 按下「儲存農場」。

請勿在地點描述中填寫不必要的身分證字號、銀行資料或其他敏感資訊。

### 2. 建立田區

1. 找到剛建立的農場。
2. 按下「新增田區」。
3. 填寫田區名稱。
4. 視需要填寫面積、面積單位、主要作物與地點描述。
5. 按下「儲存田區」。

一個農場可以建立多個田區。尚未確定面積或作物時可先留空，之後再補充。

## 四、建立農務紀錄

### 1. 進入新增紀錄

可從下列任一入口開始：

- 儀表板的「快速新增農務紀錄」
- 導覽列的「新增紀錄」

系統會顯示三個步驟：

1. 輸入農務
2. 確認資料
3. 預覽儲存

### 2. 選擇輸入方式

#### 文字輸入

選擇「文字」，直接描述實際發生的農事。例如：

```text
今天早上幫茶園澆水，大約一小時。
```

建議一次描述一件主要農務，並盡量說明日期、田區、作物、動作、資材與用量。

#### 語音輸入

1. 選擇「語音」。
2. 允許瀏覽器使用麥克風。
3. 按下「開始錄音」。
4. 說完後按下「停止錄音」。
5. 檢查辨識文字並手動修正錯字。

若瀏覽器拒絕麥克風權限，可在瀏覽器網址列旁的網站設定重新允許，或改用文字輸入。

目前正式網站的語音辨識 provider 為示範模式，因此辨識結果主要用來展示流程；重要內容請自行核對或直接改用文字輸入。

#### 圖片附件

1. 選擇「照片」。
2. 選取 JPEG、PNG 或 WebP 圖片。
3. 檢查畫面上的檔名與檔案大小。
4. 不需要的圖片可在儲存前刪除。

圖片只作為農務紀錄附件。系統不會根據照片宣稱能準確診斷病蟲害。

### 3. 選擇農場與田區

- **農場為必選項目**。
- 田區尚未確定時可以暫時不選，但系統會列為待確認資料。
- 選擇錯誤時，可以在下一步重新修正。

### 4. 讓 AI 整理資料

輸入完成後，按下「下一步：整理資料」。系統會將原始文字拆成日期、作物、農務動作、資材、使用量、天氣、備註等欄位。

## 五、確認 AI 擷取結果

每個欄位都會顯示資料來源與可信度。資料來源的意義如下：

| 顯示來源 | 意義 | 是否可直接成為正式資料 |
| --- | --- | --- |
| 使用者輸入 `USER_INPUT` | 原始文字或使用者親自補充 | 可，但仍應人工檢查 |
| 農場資料 `USER_PROFILE` | 已建立的農場或田區資料 | 可，但仍應人工檢查 |
| 開放資料 `OPEN_DATA` | 外部資料來源取得的佐證 | 不會覆蓋使用者資料 |
| AI 推論 `AI_INFERENCE` | AI 根據語句推測 | 不可，必須人工確認 |
| 未知 `UNKNOWN` | 沒有足夠資訊 | 不可，應補充或保持待確認 |

重要原則：

- 即使 AI 顯示很高的可信度，也不代表內容已被正式確認。
- AI 不應自行補寫農藥、肥料、用量、稀釋倍數、天氣、操作者或農學效果。
- 如果 AI 整理錯誤，直接修改欄位即可；修改後來源會改為使用者輸入。
- 無法確認的欄位可以保持空白，紀錄會以待確認狀態保存。

確認完成後按「下一步：完整預覽」。

## 六、預覽與儲存

預覽畫面會再次顯示：

- 原始輸入
- 擷取後的欄位
- 每個欄位的資料來源
- 尚未確認的項目

請完整閱讀後再按「確認並儲存草稿」。

儲存後可能出現的狀態：

| 狀態 | 說明 |
| --- | --- |
| 待確認 `NEEDS_CONFIRMATION` | 尚有缺漏或未確認資料 |
| 草稿 `DRAFT` | 資料已補齊，但尚未標示為正式確認 |
| 已確認 `CONFIRMED` | 已由有權限的人員完成確認 |
| 已封存 `ARCHIVED` | 紀錄保留但不再作為日常使用資料 |

## 七、農場日誌與產銷履歷草稿

進入任一農務紀錄後，可使用：

- **產生日誌草稿**：將已確認資料整理成農場日誌。
- **產銷履歷申報草稿**：將資料整理為申報用草稿。
- **確認完成**：將符合條件的紀錄標示為已確認。
- **PDF**：下載農場日誌 PDF。
- **列印**：開啟瀏覽器列印功能。

產銷履歷內容只能作為「申報草稿」，不代表已符合所有法規，也不會自動送出申報。

若按下「確認完成」後系統拒絕操作，通常表示仍有缺漏欄位，或某些 AI 推論尚未經人工修正。

## 八、品牌文案

### 1. 建立品牌資料

進入「品牌文案」，選擇農場後填寫：

- 品牌名稱
- 產地
- 農法
- 經營理念
- 產品特色
- 永續作法
- 認證資訊
- 聯絡方式
- 品牌故事素材

只填寫可確認的真實資料。沒有認證時不要填寫「有機」或其他認證名稱。

### 2. 選擇生成條件

可選擇：

- 內容類型：品牌故事、商品介紹、商品標語、Facebook、Instagram、顧客問答或出貨說明
- 目標客群：家庭、年輕族群、銀髮族、送禮需求、餐廳與商家
- 品牌語氣：樸實真誠、溫暖故事、專業可信、年輕生活感、送禮質感、永續環保
- 文字長度：短、中、長

按下「產生品牌文案草稿」後，請檢查標題、內文、行動呼籲、Hashtag、使用事實與待確認項目。

### 3. 禁止未經證實的宣稱

沒有可驗證依據時，不應使用下列宣稱：

- 無毒、有機、零農藥
- 治療效果或健康功效
- 通過認證
- 第一名、最佳
- 政府推薦

文案確認後可以儲存、複製或下載純文字檔。

## 九、歷史紀錄與匯出

進入「歷史紀錄」後，可以：

- 依關鍵字搜尋
- 依狀態篩選
- 查看農場、田區、日期與版本數
- 開啟單筆紀錄
- 匯出全部農務紀錄 CSV
- 下載單筆紀錄 PDF
- 使用瀏覽器列印

CSV 可使用試算表軟體開啟。若在部分軟體中顯示亂碼，匯入時請選擇 UTF-8 編碼。

## 十、網頁資料佐證

進入「資料佐證」，輸入要查證的問題或主張，也可以選擇要連結的農務紀錄。搜尋代理只會從管理員核准且已啟用的來源搜尋，結果會保存：

- 來源名稱、網頁標題與原始網址
- 找到的相關原文段落
- 相關度、Provider 與查詢時間
- 是否找到候選內容及來源讀取錯誤

「相關」不代表內容一定支持該主張。請點選「開啟原始資料」，檢查上下文、發布日期與適用作物。網頁佐證只用來輔助判斷，不會直接改寫農民輸入的內容。

### 農業問答

從主選單進入「農業問答」，輸入栽培、肥培、病蟲害或其他農業問題。系統會依序：

1. 搜尋已啟用的可信網站。
2. 擷取與問題相關的原文段落。
3. 只根據這些段落整理回答。
4. 在答案下方列出引用來源與原始網址。
5. 保存對話及本次使用的佐證快照。

若核准來源沒有足夠資料，系統會回答資料不足而不自行補寫。農藥、稀釋倍數、安全採收期與法規問題如果沒有主管機關來源，系統不會提供確定用量或操作結論。

## 十一、管理後台

管理員可進入「管理後台」查看：

- 可信網站來源
- 使用者與角色
- 農業詞彙修正
- 提示詞版本
- AI 呼叫紀錄
- 系統稽核紀錄

### 設定可信網站

1. 輸入來源名稱與完整 `http` 或 `https` 網址。
2. 「只搜尋這一頁」適合固定文章或手冊頁面。
3. 「搜尋同網域相關頁面」會搜尋站內與問題相關的子頁面；若設定 Tavily，搜尋範圍仍會限制在核准網域。
4. 不再使用的來源可以停用；刪除來源後，既有佐證快照仍會保留。

新增語音辨識詞彙時，請填寫錯誤詞、正確詞與分類。管理員設定來源、詞彙與其他操作都會留下稽核紀錄。

## 十二、示範模式

不想註冊時，可從首頁進入「免登入示範模式」。

示範流程包含：

1. 輸入農務文字
2. 查看 AI 擷取結果
3. 補充未知欄位
4. 產生日誌草稿
5. 模擬確認

示範模式的資料只存在目前頁面，不會寫入正式農場資料庫。關閉或重新整理頁面後，內容可能消失。

## 十三、常見問題

### 無法登入

- 確認 Email 拼字與大小寫。
- 確認密碼至少為註冊時使用的完整內容。
- 如果仍無法登入，請聯絡管理員確認帳號狀態。

目前系統尚未提供自行重設密碼功能。

### 無法錄音

- 檢查瀏覽器是否允許麥克風。
- 建議使用最新版 Chrome、Edge 或 Safari。
- iPhone／iPad 請確認網站不是在限制權限的內嵌瀏覽器中開啟。
- 無法錄音時可直接改用文字輸入。

### 照片上傳失敗

- 確認格式為 JPEG、PNG 或 WebP。
- 確認檔案未超過畫面提示的大小限制，目前預設為 10 MB。
- 網路不穩定時，請減少一次上傳的照片數量後重試。

### 為什麼不能確認完成

通常是因為：

- 還有待確認欄位
- AI 推論欄位仍有內容但尚未由使用者修正
- 使用者沒有該農場的確認權限

返回紀錄內容，補齊資料後再試一次。

### AI 產生的內容不正確

不要直接使用。請回到欄位確認畫面修正事實資料，或重新整理品牌資料後再生成。AI 內容必須由人負責最後確認。

### 系統顯示資料暫時無法取得

這通常代表外部資料服務尚未設定或暫時中斷，不影響文字農務紀錄與草稿功能。

## 十四、資料安全提醒

- 密碼會以安全雜湊方式保存，系統不保存明文密碼。
- 登入使用 HttpOnly Cookie，請勿將瀏覽器 Cookie 傳給他人。
- 圖片與音檔使用私有物件儲存，但仍應避免上傳身分證、銀行帳戶等無關敏感資料。
- 共用裝置使用完畢後務必登出。
- AI 與外部服務可能處理使用者提供的文字；正式輸入前應移除不必要的個人資料。
- 產銷履歷、認證、用藥與用量資訊仍應依原始單據、包裝標示及主管機關規定核對。

## 十五、目前線上版本設定

| 項目 | 目前狀態 |
| --- | --- |
| 網站 | Vercel Production |
| 資料庫 | Neon PostgreSQL |
| 圖片與音檔 | Private Vercel Blob |
| AI | Mock provider |
| 語音辨識 | Mock provider |
| 開放資料 | Mock mode |

Mock 模式可以完整展示操作流程，但不是正式 AI、正式語音辨識或官方開放資料。日後設定 Gemini、外部語音服務與政府 API 後，才會使用對應真實服務。

## 十六、取得協助

回報問題時，請提供：

1. 發生問題的頁面
2. 操作步驟
3. 畫面顯示的中文錯誤訊息
4. 使用的裝置與瀏覽器
5. 發生時間

請勿在問題回報中附上密碼、Session Cookie、API Key、完整身分資料或未遮罩的資料庫網址。
